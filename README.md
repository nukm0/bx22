# Marketplace — обновление личного кабинета магазина

## Изменения
- В личном кабинете у каждого объявления отображается отметка «Только магазин» или «Частное объявление».
- Главная лента не показывает объявления, опубликованные только в магазине; каталог магазина показывает только магазинные объявления.
- Добавлен пункт «ЛК магазин» для демо-ролей «Владелец» и «Магазин». В нём есть статистика, магазинные объявления, создание, редактирование и удаление, а также отзывы с возможностью отправить оспаривание.
- «Мои подписки» оформлены градиентными карточками. Подписка на профиль ведёт к частным объявлениям, подписка на магазин — к магазинным объявлениям.
- Форма оценки продавца добавляет отзыв в локальную демо-очередь модерации.

## Запуск
`npm install` затем `npm run build`.

## Ограничения демо
Данные хранятся локально в браузере. Роли, статистика, жалобы и модерация не являются серверной системой; для продакшена потребуется API и база данных с серверной проверкой прав.
